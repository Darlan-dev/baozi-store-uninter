# Checklist dos prints do Postman

Faça os testes reais com a aplicação executando.

## Obrigatórios

- [ ] POST /clientes
- [ ] POST /produtos
- [ ] POST /pedidos
- [ ] GET /clientes
- [ ] GET /produtos
- [ ] GET /pedidos
- [ ] GET /clientes/{id}
- [ ] GET /produtos/{id}
- [ ] GET /pedidos/{id}
- [ ] DELETE /clientes/{id}
- [ ] DELETE /produtos/{id}
- [ ] DELETE /pedidos/{id}

## Atenção

Os dados dos prints devem ser compatíveis com o estudo de caso do PDF.
